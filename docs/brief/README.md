## The five rules that matter most

1. Four services first. No sub-brand names or logos. Pillar Live no longer exists.
2. Never invent a fact (numbers, names, quotes, menus). Write `[NEEDS CLIENT: ...]` instead.
3. Only photos from `05-assets/images/`. AI images are fine for mood and food, never as a real event.
4. Phone first. The client's biggest complaint was how the old site's type felt on a phone.
5. Work on your own version; questions and hand-in go to Purusharth. Never contact the client.
